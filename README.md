## Descrição

Sistema desenvolvido para facilitar o gerenciamento de uma biblioteca, permitindo controlar livros, usuários e empréstimos.

## Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Registro de empréstimos
- Registro de devoluções
- Pesquisa de livros
- Controle de disponibilidade

## Pré-requisitos

Antes de executar o projeto, é necessário ter instalado:

- Git
- Node.js
- npm
